## ส่วนที่ใช้ต่อในครั้งที่ 3

คัดลอก **Entry และ Exit Criteria ของทีม** จากใบงานครั้งที่ 1 มาไว้ตรงนี้ด้วย เพื่อให้หาง่าย

| ประเภท | เกณฑ์ของทีม |
|---|---|
| Entry | มีไฟล์ทดสอบที่ทีมสร้างเอง ไม่มีใบหน้าบุคคลจริง ครบทุกค่าขอบของขนาด (100 MB − 1 ไบต์ · 100 MB · 100 MB + 1 ไบต์) และทุกประเภทในรายการที่รองรับและไม่รองรับ |
| Entry | Frontend ที่ commit ระบุได้ รัน `next dev` ได้ และเปิด `/detect` แบบ Guest ได้โดยไม่ถูกส่งไปหน้าเข้าสู่ระบบ |
| Exit | รันกรณีทดสอบของขนาดและประเภทไฟล์ครบทุกข้อในชุดอ้างอิง และทุกข้อมีไฟล์หลักฐานหรือสถานะ Not Executed พร้อมเหตุผล |
| Exit | ทุกกรณีที่ไฟล์เกิน 100 MB หรือประเภทนอกรายการแต่ระบบยังรับ ถูกบันทึกเป็นข้อที่ไม่ผ่านพร้อมหลักฐาน และไม่มีข้อใดถูกปิดโดยไม่ได้รันซ้ำ |

## ทีมที่ยังไม่มีเอกสารออกแบบของโครงงาน

วาดภาพส่วนประกอบจากโค้ดหรือแผนที่มีจริง แล้วติดป้ายว่า “สร้างย้อนหลัง” หรือเขียนช่องว่างว่าขาดเอกสารใด ใครรับผิดชอบ จะได้เมื่อไร · ห้ามแต่งข้อค้นพบที่ไม่ได้ตรวจจริง
